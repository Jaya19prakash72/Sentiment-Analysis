About this dashboard

A complete local ML project designed for learning, demonstrations and mini-project presentations.

How it works

  1. A labeled CSV dataset is loaded when Flask starts.
  2. The custom Naive Bayes model learns word frequencies for Positive, Negative and Neutral classes.
  3. New text is tokenized and scored using Bayesian probabilities.
  4. The result is returned through a JSON API and rendered in this dashboard.
